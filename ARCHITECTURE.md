# 斐讯R1智能音箱控制器 - 整合方案

## 项目概述

基于云知声SDK + R1_Controller 开发的全新斐讯R1智能音箱控制器。

## 功能模块

### 1. 语音交互
- ✓ 唤醒词检测 (云知声)
- ✓ 语音识别 (ASR)
- ✓ 意图理解 (NLU + LLM)
- ✓ 语音播报 (TTS)

### 2. 音乐服务
- ✓ 网易云音乐 (VIP解析)
- ✓ 本地音乐播放
- ✓ 在线搜索播放

### 3. 智能家居
- ✓ HomeAssistant集成
- ✓ 语音控制灯光/开关
- ✓ 场景联动

### 4. AI对话
- ✓ 大模型接入 (OpenAI/硅基流动/本地)
- ✓ 智能问答
- ✓ 意图学习

### 5. Web管理
- ✓ 设备控制 (截屏/点击/滑动)
- ✓ 配置管理
- ✓ 音乐播放界面
- ✓ 智能家居控制面板
- ✓ AI对话界面

## 技术栈

| 层级 | 技术 |
|------|------|
| 前端 | HTML/CSS/JavaScript (Bootstrap) |
| 后端 | Python FastAPI |
| 语音 | 云知声SDK (unisound APK) |
| AI | OpenAI API / 硅基流动API / Ollama |
| 音乐 | 网易云音乐API |
| 家居 | HomeAssistant REST API |
| 部署 | Python + Buildozer (打包APK) |

## 部署方式

### 方式1: Web服务 (推荐)
```bash
# 在R1上安装Termux
# 安装Python和依赖
pip install -r requirements.txt
python main.py

# 浏览器访问 http://R1_IP:8080
```

### 方式2: 打包APK
```bash
# 使用Buildozer打包
buildozer init
buildozer android debug
```

## 配置文件

配置文件位于 `config/config.json`:

```json
{
  "device": {
    "ip": "192.168.1.xxx"
  },
  "llm": {
    "enabled": true,
    "api_url": "https://api.xxx.com/v1",
    "api_key": "sk-xxx",
    "model": "gpt-3.5-turbo"
  },
  "music": {
    "enabled": true,
    "source": "netEase",
    "local_api": "http://192.168.1.x:3000"
  },
  "ha": {
    "enabled": true,
    "url": "http://192.168.1.x:8123",
    "token": "xxx"
  },
  "unisound": {
    "enabled": true,
    "package": "com.unisound.vui"
  }
}
```

## 语音命令示例

| 命令 | 响应 |
|------|------|
| 播放周杰伦的歌 | 搜索并播放周杰伦的歌 |
| 暂停 | 暂停播放 |
| 下一首 | 切换到下一首 |
| 声音大一点 | 增加音量 |
| 打开客厅灯 | 通过HA打开灯光 |
| 今天天气怎么样 | 播报天气信息 |
| 现在几点 | 播报当前时间 |
| 你好 | AI对话回复 |
